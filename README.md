# 김도윤 학업 포트폴리오 (교육용 샘플)

경상국립대학교 바이브코딩 캠프 후속 과정 「AI 활용 학업 포트폴리오 웹사이트 완성 및 배포」의 완성 샘플입니다.
인물과 내용, 이미지와 PDF는 모두 샘플 자료입니다.

## 폴더 구조

```
portfolio/
├─ index.html          사이트 본문 (배포되는 파일, 이름 변경 금지)
├─ README.md           이 설명 파일 (GitHub 저장소 첫 화면에 표시)
├─ images/             사이트에 보이는 사진
│  ├─ profile.jpg              프로필 사진
│  ├─ capstone-planter-01.jpg  프로젝트 1 카드 이미지
│  ├─ heat-exchanger-graph.png 프로젝트 2 카드 이미지
│  ├─ reading-stand-model.jpg  프로젝트 3 카드 이미지
│  └─ og-image.jpg             링크 미리보기 카드 이미지 (1200×630)
└─ files/              클릭하면 열리는 근거 자료
   ├─ capstone-drawing.pdf     도면
   └─ heat-exchanger-report.pdf 보고서
```

## 규칙

- 파일 이름은 영문 소문자, 숫자, 하이픈(-)만 사용합니다.
- GitHub에는 portfolio 폴더 자체가 아니라 **폴더 안의 내용**을 올립니다. index.html이 저장소 맨 위에 있어야 합니다.
